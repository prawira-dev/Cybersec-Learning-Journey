# Fundamentals — Roadmap & Core Topics for Cybersecurity

This brief guide lists the fundamental topics that required to build foundations in cybersecurity.

## [Cybersecurity Overview](./01-fundamentals/cybersecurity-overview.md)
- **Defense and Offense:** Demand, Core Goal, Tools, Key Focus
- **CIA Triad:** Confidentiality, Integrity, Availability — definitions and example controls.
- **Defense-in-Depth:** Layered security controls across physical, network, host, application, and data layers.
- **Risk Management:** Risk identification, assessment, mitigation, and residual risk.

## Computer Fundametals
- **Minimum Computer System:** Hardware components, CPU, RAM, storage, and I/O architecture.
- **Computer Types:** Servers, workstations, embedded systems, and ICS/OT devices.
- **Client Server Basic:** Fundamental concepts of request-response models and distributed systems.
- **Virtualization Basic:** Virtual machines and containers.
- **Cloud Computing Basic:** IaaS, PaaS, and Saas.

## Operating Systems & Endpoints
- **Linux fundamentals:** Shell, file permissions, processes, systemd, auditing.
- **Windows fundamentals:** Active Directory, NTFS, PowerShell, event logs.
- **Endpoint hardening:** Patch management, antivirus/EDR, host-based firewalls.
- **OS Security:** User Account Control (UAC), principle of least privilege, kernel-level protections, process isolation, and secure boot concepts.

## Software Basic
- **Data Representation:** Binary, Hexadecimal, Base64, and how computers represent numbers, text, and memory addresses.
- **Data Encoding:** Learn how computer encodes characters, from ASCII to Unicode's UTF.
- **Programming Languages:** Basics of Python, Java, C++, SQL, etc.

## Networking & Infrastructure
- **OSI / TCP-IP Models:** Layers and common protocols (IP, TCP, UDP, ARP, DNS).
- **Subnetting & Routing:** IP addressing, CIDR, NAT, and basic routing concepts.
- **Network Services:** DHCP, DNS, HTTP/HTTPS, SMTP and how to secure them.

## Cryptography & Identity
- **Cryptography basics:** Symmetric vs asymmetric, hashing, digital signatures, PKI.
- **TLS/SSL:** How it works, certificates, and chain of trust.
- **IAM:** Authentication vs authorization, MFA, SSO, and principle of least privilege.

## Threats & Attack Vectors
- **Malware types:** Viruses, worms, trojans, ransomware, and fileless malware.
- **Social engineering:** Phishing, pretexting, baiting.
- **Network attacks:** MITM, ARP spoofing, DDoS.

## Web & Application Security
- **OWASP Top 10:** SQL injection, XSS, CSRF, broken authentication, insecure deserialization.
- **Secure coding basics:** Input validation, output encoding, secure session management.
- **API security:** Authentication, rate limiting, input validation.

## Security Testing (Offensive Concepts)
- **Reconnaissance & enumeration:** OSINT, port scanning (nmap), service fingerprinting.
- **Vulnerability assessment:** CVE lookup, vulnerability scanners, prioritization.
- **Exploitation & post-exploitation:** Principles and ethics (perform only in authorized labs).

## Defense & Security Operations (Defensive Concepts)
- **Logging & monitoring:** Log sources, aggregation, retention strategies.
- **SIEM & alerting:** Use cases, detection engineering, and tuning.
- **Incident response:** IR phases (Prepare, Detect, Contain, Eradicate, Recover) and basic forensics.

## Cloud & Modern Infrastructure
- **Cloud security basics:** Shared responsibility model, identity and network security in cloud environments.
- **Containers & orchestration:** Docker security and Kubernetes hardening.

## Governance, Compliance & Legal
- **Common regulations:** GDPR, PCI-DSS (high-level) and company policies.
- **Security policies:** Acceptable use, access control, and incident policies.

## Tools & Lab Platforms
- **Common tools:** Wireshark, tcpdump, nmap, Burp Suite, Metasploit, Splunk/Elastic, Sysmon.
- **Labs & practice platforms:** TryHackMe, Hack The Box, VulnHub, CTFs (use isolated, legal environments).

## Career & Skill Development
- **Roles & focus areas:** SOC analyst, incident responder, penetration tester, threat hunter.
- **Entry certifications:** CompTIA Security+, eJPT; advanced goals like OSCP.
- **Continuous learning:** Follow blogs, CVE feeds, MITRE, and join the community.

## Resources & References
- **Standards & frameworks:** MITRE ATT&CK, NIST CSF, OWASP.
- **Practice platforms:** TryHackMe, Hack The Box, VulnHub.
- **Books & blogs:** Recommendations available on request (cloud, forensics, red/blue topics).
