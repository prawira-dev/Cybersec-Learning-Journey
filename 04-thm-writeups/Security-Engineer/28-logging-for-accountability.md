## Task 4: Types of Logs and Data Sources
* Covers different categories of logs available across an enterprise network:
    * **Manual log sources**: Any log that is manually written or composed by an author (e.g., Change logs).
    * **Automated log sources:** Any logs that are automatically generated by default, for example, a configuration, tool, or from a developer (System logs, Application logs).
    * **Other types of logs:** Some logs may not be categorized but are often required for compliance (e.g., Email logs, Messaging or other communication).

* **Question:** A change log is an example of what log source?
* **Answer:** manual log sources
* **Question:** An application log is an example of what log source?
* **Answer:** automated log sources
